## Run it


`main.ts` (Node 22, standard library only) copies `entry.png` to `/output/entry.png`. The output is a JPEG (1024×1024, ~250 KB), inside the gate limits (≤ 1 MiB, ≤ 1024×1024). Running it twice produces byte-identical output: it is a plain file copy.
